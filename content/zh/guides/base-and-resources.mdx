本攻略把 Steam 商店介绍与当前官方更新整理成一套可执行的基地流程。抢先体验期间数值可能变化，因此本文关注可见的供需关系，不提供僵化的唯一建造顺序。

### 如何理解本文建议

- **已确认事实**：直接来自官网、Steam 商店或官方更新。
- **实用顺序**：用于保护食物、运输和人手的保守做法，不是官方公式。
- **媒体观察**：会单独标注，不能当成必然机制。

<Callout type="source" title="资料边界">
  官方资料能够确认下文提到的建筑和生产工具，但没有公布一套适用于所有存档的最佳基地布局。请以当前版本的科研树、材料成本和人员面板为准。
</Callout>

## 基地循环

### 官方能够确认的循环

Steam 商店说明，殖民地会依靠在 Tyris 星系获得的资源成长。外出探索带回材料与人口，基地再把这些投入转化为食物、住房、科研、装备和下一次探索所需的战力。

### 一套安全的运行顺序

1. 查看食物、空余仓储、当前生产和可用人员。
2. 收取或搬运滞留在资源建筑中的产物。
3. 为即将停工的关键生产线补充原料。
4. 完成一个能够解除当前瓶颈的科研、建筑或升级。
5. 给基地日常需求保留足够人员与物资。
6. 准备下一次探索需要的装备和复活物品。

前五步属于实用管理循环；官方确认了这些系统，但没有指定这一固定优先顺序。

## 食物、治疗与舒适度

### 扩张前先稳定食堂

官方更新明确提到食堂和厨房，并说明士兵会在食堂用餐、厨房升级会提高每批食物产量。食物既是生产问题，也是配送问题：原料、加工、搬运和实际用餐都要连通。

### 区分治疗、体力和士气

诊所负责治疗；`休假（Time Off）`和带薪休假与恢复及排班余量有关。舒适与繁荣属于官方殖民地管理框架，但公开资料没有给出舒适度与某项状态之间的通用换算公式。

| 需求 | 首先检查 | 证据范围 |
| --- | --- | --- |
| 食物 | 食堂能否使用、厨房投入与产出、配送队列 | 官方系统；数量以游戏内为准 |
| 治疗 | 诊所是否可用、士兵能否到达 | 官方系统 |
| 体力 | 工作安排、`休假`、带薪休假 | 官方恢复工具；具体时间可能随版本变化 |
| 士气与忠诚 | 最近探索结果、政策、薪酬和生活条件 | 多项官方影响因素；没有单一公开公式 |

<Callout type="info" title="实用原则">
  食物配送已经失灵时，不要扩大人口或同时开启多条长期生产。仓库里有原料并不等于士兵能吃到食物，真正瓶颈可能在厨房、搬运人员或食堂通路。
</Callout>

## 建筑与生产

### 有意识地使用仓库生产模式

官方 7 月更新确认：建成仓库后可解锁三种制造模式。

- **订单模式（Order Mode）**：生产指定数量，材料不足时暂停。
- **库存模式（Stock Mode）**：让某项物品保持在设定库存线以上。
- **自动模式（Auto Mode）**：无限生产，缺料暂停，补料后自动恢复。

一次性建造需求适合订单模式；反复消耗的探索补给适合库存模式；只有在不会吞掉更稀缺原料时才使用自动模式。这些用途属于实用建议。

### 补上搬运缺口

资源运输站可以安排士兵收集其他资源建筑的产出；升级运输站后，物品能够直接送入仓库。生产看似停摆时，应检查整条链：

`采集 / 采矿 / 伐木 → 资源运输站 → 仓库 → 工坊 / 厨房 → 可用库存`

不同版本与设施下，资源也可能留在地面或建筑库存里。增加生产建筑前，先确认问题是产量不足还是物品没有被搬走。

<span id="workforce"></span>
## 劳动力分配

### 先自动分配，再人工复查

官方更新确认了自动分配、临时分配、岗位锁定和按工种控制参与资格；建筑面板也会突出该岗位需要的工作属性。

1. 打开建筑详情，确认高亮的需求属性。
2. 用自动分配填补明显空缺。
3. 把关键专业人员锁定在不能中断的岗位。
4. 禁止属性不合适的士兵参加某类自动分配。
5. 为搬运、治疗、休假或突发短缺留出待命人员。

### 避免“所有岗位都塞满”的陷阱

满员不等于可持续。殖民地还需要移动、恢复、进食和替补劳动力。产量下降时，应先检查人员可用性和搬运耗时，再判断是否真的需要升级建筑。

<span id="shortages"></span>
## 短缺优先级

### 找到断点，而不是只看最响的警告

| 表现 | 首先检查 | 接着检查 |
| --- | --- | --- |
| 士兵饥饿 | 食堂通路和成品食物 | 厨房原料、人员和搬运 |
| 工坊停产 | 建筑内是否有正确原料 | 仓库库存与运输路线 |
| 产物堆积 | 运输站人员 | 仓库容量与距离 |
| 科研停滞 | 所需材料和科研队列 | 同类原料是否被其他生产消耗 |
| 大量岗位空缺 | 可用成年士兵和岗位资格 | 休假、治疗、年龄和临时分配 |

### 实用恢复顺序

多条生产链同时崩溃时，先恢复即时生存需求，再恢复运输，然后补齐关键建筑的输入，最后才继续扩张。这不是官方排名，而是防止一个短缺引发更多短缺的控制方法。

<span id="expansion"></span>
## 扩张检查表

### 放置或升级新建筑之前

- 确认指挥中心等级允许计划中的人口与进度。
- 确认施工材料没有预留给食物、治疗、捕获弹或复活物品。
- 确认有人具备相关属性，而且排班仍有余量。
- 确认运输站和仓库能接住新增产出。
- 决定产物应该使用订单、库存还是自动模式。
- 先解决一个瓶颈，再开启多条未完成的生产链。

### 外出探索之前

收取基地成品、补齐重复消耗的库存目标、确认食物覆盖，并确保关键生产既有原料也有人手。目标不是让基地完美，而是避免回来时发现生产链因可预防的问题崩溃。

## 常见问题与来源

### 常见基地问题

- **明明有资源却不能使用：**检查资源是在地面、生产建筑、运输站还是仓库。
- **自动生产不恢复：**检查所有输入材料，并确认当前确实选择了自动模式。
- **有食物但仍然饥饿：**检查配送和食堂通路，不要只看厨房总量。
- **士兵不断离开关键岗位：**使用岗位锁定，然后确认其是否被治疗或恢复需求带走。
- **等待科研时基地无事可做：**利用科研队列，并整理搬运、食物和探索补给，而不是盲目开新工程。
