# Pax Autocratica 五语言攻略扩展设计

## 目标

在现有 Pax Autocratica 粉丝 Wiki 上完成五篇可实际阅读的攻略，并将全站语言扩展为英语、简体中文、法语、俄语和德语。全部内容先在本地完成、检查并运行预览；未经用户明确确认，不上传 GitHub。

## 语言与路由

支持以下语言路径：

- 英语：`/en`
- 简体中文：`/zh`
- 法语：`/fr`
- 俄语：`/ru`
- 德语：`/de`

每种语言包含首页、攻略导航页和五篇攻略页，共 7 个主要页面；全站合计 35 个主要本地化页面。语言切换器使用紧凑的下拉菜单，并在切换时保留当前页面。例如，用户在 `/zh/guides/base-and-resources` 选择德语后进入 `/de/guides/base-and-resources`。

所有语言均使用独立的翻译和 MDX 文件。缺少内容时返回 404，不使用其他语言内容冒充翻译。

## 攻略范围

攻略导航页只展示以下五个真实且可点击的项目，不再展示“状态与政策”“经济与生产”“法令”等错误占位项目：

1. 士兵与繁育
2. 基地与资源
3. 俘虏与转化
4. 兵器与战斗
5. 探索与 BOSS

### 士兵与繁育

保留现有英语和中文内容，补充法语、俄语和德语版本。现有事实边界不因翻译而改变。

## 页面内容结构

每篇攻略采用统一的阅读结构：

- 本地化标题、摘要、更新时间和 SEO 元数据
- 游戏截图或官方宣传素材，并标注来源
- 玩法概览和适用场景
- 分步骤说明
- 数据表格或对照表
- 实用提示、限制条件和易错点
- 事实可信度提示
- 相关站内攻略
- 可点击的外部来源列表

页面保持现有深色、军事工业风格和响应式布局，不重新设计视觉系统。

## 内容与资料归档

最终共有 25 份攻略 MDX：

```text
content/
  en/guides/*.mdx
  zh/guides/*.mdx
  fr/guides/*.mdx
  ru/guides/*.mdx
  de/guides/*.mdx
```

现有英语和中文“士兵与繁育”继续使用，因此需要新增 23 份攻略文档。

每条研究来源单独保存为 Markdown 文件：

```text
research/
  soldiers-and-breeding/
  base-and-resources/
  captives-and-conversion/
  weapons-and-combat/
  exploration-and-bosses/
```

每份资料文件记录来源标题、来源类型、URL、访问日期、它能支持的具体结论，以及为写作整理的摘要。不会把受版权保护的第三方文章全文复制到本地。

来源优先级如下：

1. Pax Autocratica 官网、Steam 商店与官方公告
2. 官方 YouTube 或其他官方社群内容
3. 可信媒体报道和高质量视频
4. 明确标注为“玩家测试”的社区材料

不会引用竞对攻略网站。所有准备展示给用户的外部链接在完成前都需要检查可访问性，不保留 404 或打不开的链接。第三方材料不会被表述为官方事实。

## 组件与数据变化

- 路由配置增加 `fr`、`ru` 和 `de`。
- 增加三份全站界面翻译文件。
- 语言切换器从双语言按钮改为五语言下拉菜单。
- 攻略导航、桌面侧栏、移动导航、首页入口和页脚统一使用五个真实攻略项目。
- 攻略卡片全部变为有效链接，移除错误的“计划中”卡片。
- 现有 MDX 加载器继续作为攻略正文和 SEO 元数据的唯一来源。
- 不增加数据库、搜索系统、账号、评论、动态 Steam 数据或实时接口。

## 异常处理

- 无效语言或不存在的攻略返回 404。
- 图片必须提供替代文字；无可靠图片时宁可省略，也不使用误导性素材。
- 无足够资料支持的表格单元格明确写成“官方未说明”，不猜测数值。
- 外部来源失效时不将其加入页面；后续失效可从来源列表移除而不影响正文路由。

## 测试与验收

完成前检查以下内容：

- 35 个主要本地化页面均可访问。
- 五种语言的首页、攻略导航和攻略详情没有错误语言回退。
- 语言下拉菜单可使用键盘操作，并能保留当前页面路径。
- 五篇攻略在导航页、侧栏、首页和页脚中的名称及链接一致。
- 每篇攻略可以渲染标题层级、步骤、表格、提示框、图片、站内链接和来源链接。
- 每个页面具有本地化 `title`、`description`、规范链接和多语言替代链接。
- 所有外部来源链接可打开，且不存在竞对攻略站链接。
- 电脑端和手机端无页面空白、横向溢出、卡片错位或文字明显溢出。
- ESLint、单元测试、生产构建和 Playwright 浏览器测试全部通过。
- 最终启动本地网站供用户查看；只有用户明确确认后才上传 GitHub。

## 不在本次范围内

- 西班牙语和日语
- 实时玩家人数、活跃度或评价统计
- 用户账号、评论、评分或数据后台
- 没有资料支持的数值推测或游戏机制扩写
- 用户确认前的 GitHub 推送或线上部署
